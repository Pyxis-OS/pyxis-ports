# Linked runtime notices

The LLVM runtime notices and selected source notices are from PyxisOS/pyxis-llvm
`3d69e83c443e2acf7cf83db35037899f99cf76b3` (LLVM 23.1.3):
[immutable source](https://git.internal/PyxisOS/pyxis-llvm/src/commit/3d69e83c443e2acf7cf83db35037899f99cf76b3).
The component licences retain the Apache LLVM exception and legacy MIT/NCSA
sections. CREDITS files referenced by those licences are included.

LPegLabel source notices come from the five compiled C units and their headers
at `912b0b9e8641074408ffc2259e069b188e0c717b`; its full MIT licence is staged
separately. SDK libc, TLSF and filesystem notices and the exact SDK manifest
and toolchain revision are copied from the SDK actually used by each build.
The original Pyxis adapter sources and patches accompany the runnable bundle.
